# Zambo

The verifiable work layer for AI: 153 tools behind one remote MCP endpoint, continuity across AIs, and a verifiable AER-1 receipt for every job. An agent connects over Streamable HTTP, does the work, and each job closes with a receipt a third party can check against the record.

[https://zambo.dev/mcp](https://zambo.dev/mcp)

## Features

- 153 tools behind one remote MCP endpoint (36 on the default surface), callable from any MCP client
- A verifiable AER-1 receipt for every job, so completed work can be checked after the fact
- Continuity and handover: a job started in one AI can be picked up in another without starting over
